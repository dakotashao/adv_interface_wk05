# adv_interface_wk05

Advanced Interface, week 5: Lists.
A list of autumn leaves in three groups. Hover a leaf and the big leaf behind the list changes to it; a group row expands, a leaf row opens its page. Wind runs through the whole system.

| Set | Concept | Prototype |
|---|---|---|
| 1 | Autumn, Full Bleed | [Open](https://dakotashao.github.io/adv_interface_wk05/autumn-full/) |
| 2 | Dominoes List: a photo editor's Adjust list in the Week 4 Dominoes Drag system, three takes (rows that become the slider in place; rows that tip back like a wheel; a wheel with a domino tape) | [Open](https://dakotashao.github.io/adv_interface_wk05/domino-list/) |

Each set lives in its own folder with a self-contained `index.html`. Spec is inside each prototype (Spec button).
Leaf silhouettes traced from Wikimedia Commons photos; sources and licenses in [CREDITS.md](CREDITS.md).
